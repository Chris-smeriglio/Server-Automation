# Project Goals
Overall this project is to achieve 2 goals simultaneously. Firstly as a home server admin, it can get fairly convoluted to ensure that everything is functional and reliable. Secondly, as an unemployed software engineer this allows me to exhibit some of my skills while keeping my skills fresh.
### Validate Health
- Ensure that core programs are regularly running
- Validate that software version matches latest release
- Utilize SMART drive monitoring to evaluate the health of HDDs
- Ensure free space is >20% on ZFS pool
### Test Automation
- Automate validating features of various programs
### Email status
- when an issue occurs, an email is sent
- every week a status email is sent regardless
### Automation improvements
- revise reboot scheduled tasks such as updates
- test functions to run nightly
